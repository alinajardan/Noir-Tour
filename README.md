# NOIR TRAVEL

Fictional luxury travel agency: a **portfolio concept website**. It is not a real company.
All itineraries, prices and contact details are examples. The contact form sends nothing (no backend).

Static site: `index.html` + `assets/images/`. No build step, no dependencies (Google Fonts are optional; system fonts are the fallback).

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

## Publish with GitHub Pages
1. Create a repository and upload all files, keeping the folder structure.
2. Settings → Pages → Source: *Deploy from a branch* → branch `main`, folder `/ (root)` → Save.
3. After a minute the site is at `https://<user>.github.io/<repo>/`.

## Test checklist
- Navigation, mobile menu, `Esc` closes menu/destination page
- 7 destination pages: `#dolomites #amalfi #faroe #switzerland #greece #iceland #morocco`
- Form validation and the email-draft button
- Phone, tablet, desktop widths; browser console is clean
